Encapsulation

ভেতরের জিনিস লুকাও, বাইরে শুধু যা দরকার দাও।
যেমন: ATM-এর ভেতরে কীভাবে কাজ করে জানো না, কিন্তু টাকা তুলতে পারো

👨‍👦

Inheritance

Parent class-এর সব গুণ child-এ আসে।
যেমন: মানুষ → Student, Teacher — সবার নাম-বয়স আছে

🎭

Polymorphism

একই নাম, আলাদা কাজ।
যেমন: কুকুর কামড়ায়, বিড়াল আঁচড়ায় — দুজনকেই বলা হয় "আক্রমণ করো"

🎭

Abstraction

জটিলটা লুকাও, সহজটা দেখাও।

প্রথম স্তম্ভ

Encapsulation — ক্যাপসুলের মত

💊 ওষুধের ক্যাপসুল

ভেতরে কী আছে দেখা যায় না। কিন্তু কাজ করে। কেউ সরাসরি ভেতরে হাত দিতে পারে না।

🏦 রহিমের bank account

class BankAccount {'{'}
  #balance = 0; // private — বাইরে থেকে দেখা যাবে না
  টাকাজমাও(amount) {'{'}
    if (amount <= 0) throw "Invalid!";
    this.#balance += amount;
  {'}'}
  balanceদেখো() {'{'} return this.#balance; {'}'} // শুধু দেখতে পারবে
{'}'}
const রহিমAccount = new BankAccount();
রহিমAccount.টাকাজমাও(5000);
// রহিমAccount.#balance = 999999; ← এটা কাজ করবে না! 🔒

Encapsulation মানে: validation, rules সব ভেতরে। বাইরে থেকে ভুল data দেওয়ার সুযোগ নেই।

Inheritance — বাপের গুণ ছেলেতে

👨‍👩‍👧‍👦 স্কুলের উদাহরণ

class মানুষ {'{'} // Parent class
  constructor(নাম) {'{'} this.নাম = নাম; {'}'}
  পরিচয়() {'{'} return `আমি ${'{'}this.নাম{'}'}`; {'}'}
{'}'}
class ছাত্র extends মানুষ {'{'} // মানুষ-এর সব পাবে
  constructor(নাম, রোল) {'{'} super(নাম); this.রোল = রোল; {'}'}
  পড়াশোনা() {'{'} return `${'{'}this.নাম{'}'} পড়ছে`; {'}'}
{'}'}
class শিক্ষক extends মানুষ {'{'}
  পড়াও() {'{'} return `${'{'}this.নাম{'}'} পড়াচ্ছে`; {'}'}
{'}'}
ছাত্র রহিম পাবে
পরিচয়() ✓
পড়াশোনা() ✓
শিক্ষক করিম পাবে
পরিচয়() ✓
পড়াও() ✓

DRY Principle: Don't Repeat Yourself। মানুষ class একবার লেখলাম — ছাত্র-শিক্ষক দুটোই পেল।

Polymorphism — একই কথা, আলাদা কাজ

🐾 জাবেরের পোষা প্রাণী

class প্রাণী {'{'} শব্দকরো() {'{'} return "..."; {'}'} {'}'}
class কুকুর extends প্রাণী {'{'}
  শব্দকরো() {'{'} return "ঘেউ ঘেউ! 🐕"; {'}'}
{'}'}
class বিড়াল extends প্রাণী {'{'}
  শব্দকরো() {'{'} return "মিঁয়াউ! 🐈"; {'}'}
{'}'}
// একই command — আলাদা ফলাফল
[new কুকুর(), new বিড়াল()].forEach(p => console.log(p.শব্দকরো()));
// "ঘেউ ঘেউ!" তারপর "মিঁয়াউ!"

বাস্তব code-এ উদাহরণ

// Payment — একই interface, আলাদা implementation
class Payment {'{'} pay(amount) {'{'} /* abstract */ {'}'} {'}'}
class বিকাশ extends Payment {'{'} pay(a) {'{'} return `bKash: ${'{'}a{'}'}`; {'}'} {'}'}
class নগদ extends Payment {'{'} pay(a) {'{'} return `Nagad: ${'{'}a{'}'}`; {'}'} {'}'}
// রহিম বিকাশে, করিম নগদে — এক function call
processPayment(payment, 5000) // payment.pay(5000)

গাড়ির Abstraction

হাচান গাড়ি চালায়। Engine cylinder কীভাবে কাজ করে? জানে না। স্টিয়ারিং, গ্যাস, ব্রেক — ব্যস। বাকিটা hidden।

Code-এ Abstraction

// রহিম শুধু এটুকু জানে
sendEmail(to, subject, body);
// ভেতরে আসলে কী হয়? রহিম জানে না, জানার দরকারও নেই:
// SMTP connection → auth → TLS → queue → retry → delivery...
// database save — করিম শুধু এটুকু
prisma.user.create({'{'} data {'}'});
// ভেতরে: SQL generate → connection pool → WAL → commit...

সব একসাথে — E-commerce System

class User {'{'} // Abstraction: ভেতরের জটিলতা লুকানো
  #password; // Encapsulation: password private
  constructor(name, email) {'{'} this.name=name; this.email=email; {'}'}
  pay(amount) {'{'} return `${'{'}this.name{'}'} paid ${'{'}amount{'}'}`; {'}'} // Polymorphism
{'}'}
class PremiumUser extends User {'{'} // Inheritance
  pay(amount) {'{'} return `${'{'}this.name{'}'} paid ${'{'}amount*0.9{'}'} (10% off!)`; {'}'}
{'}'}
রহিম = new User()
normal user
pays full price
করিম = new PremiumUser()
premium user
10% discount!

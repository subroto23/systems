Role-Based Access Control

কে কী করতে পারবে?

Role কারা কী করতে পারে Token-এ
superAdmin সর্বোচ্চ কর্তৃপক্ষ সব কিছু — User, Course, Settings, Analytics ♾️ Full
admin Content Team Course তৈরি, Video upload, Live Class manage 🔑 High
solver প্রশ্ন সমাধানকারী Student প্রশ্নের উত্তর দেওয়া 📝 Limited
student শিক্ষার্থী কেনা Course দেখা, Quiz দেওয়া 📚 Course Only
